# Clinician app — journeys

> **Phase 2. Not yet.** First every area of `clinician-app-checklist.md` is checked on its own,
> and the bugs it finds are fixed (Peter, 2026-10-21). See `docs/plans/ui-testing.md`.

Each journey is one real task, from start to finish. Do it as a clinician would, and tick the
feature checks (`clinician-app-checklist.md`) for each screen you pass through. Report anything odd
with Jam: **what you expected, and what happened.**

- Use made-up names only. The child is 8–17.
- For a parent's email, use your own with a `+`: `you+mom@gmail.com` arrives in your inbox.
- Open the parent's side in a **private browser window**, so you stay signed in as the clinician.
- Skip the teen app.

Times are guesses. Note how long each one really took.

---

## Journey 1 — A new family arrives (20 min)
Checks: sections 1–8.

1. Sign in. Look round My patients.
2. Add a patient: a 12-year-old, with two parents (two `+` emails).
3. On their page, edit the profile: pick an anxiety type.
4. Open the Parent access panel. Invite a third parent, then remove them.
5. Open the Clinician access panel. Look, change nothing.
6. Open the checklist and tick the first item.
7. Back on My patients: is the family there, in the right phase?

## Journey 2 — A week of monitoring (30 min)
Checks: sections 9–10, and P1.

1. On the family from Journey 1, Monitoring tab → Create monitoring form.
2. Open the parent's email in a private window, and open the form.
3. As the parent: give permission, then save **four** observations about different situations. Use
   at least one Tap & Talk on your phone if you can. Give a Fear Level each time.
4. Back as the clinician: do the four show in the Report?
5. Case Summary tab → Analyze with AI. Read it. Is every situation one the parent logged? Do the Fear
   Levels match?
6. As the parent, add one more observation. As the clinician, Re-analyze.

## Journey 3 — Building the ladder (30 min)
Checks: sections 11–14.

1. Plan tab → Create treatment plan → add a nickname.
2. Build ladder. Add two situations from the suggestions and one of your own.
3. Open one. Add two safety behaviors. Read the AI's step sentences. Would a child understand
   them? Reword one.
4. Done. Add a rung of your own. Then Show suggested rungs and add one. Are they easier versions of
   this situation?
5. Run a downward arrow on one step (DA). Take it three questions deep, then save the feared
   outcome.
6. Save ladder. Rename a rung, change a Fear Level, remove one.

## Journey 4 — The first exposure and the parent's plan (25 min)
Checks: sections 15–17, and P3–P5.

1. Set up the easiest rung for a day this week, and mark it "do this next".
2. Accommodations → Build plan. Add two accommodations. Add one from the parent's suggestions if
   any. Mark one "Working on it".
3. Turn on "Parents can see the child's progress" (Parent access panel).
4. As the parent (private window, invite email): set a password, look at Home, write "How did it
   go?" on the accommodation, and answer the weekly check-in on Progress.
5. Back as the clinician: do the parent's notes show?
6. Progress tab → set up an experiment with the parent.

## Journey 5 — Sessions and messages (20 min, needs a phone)
Checks: sections 18–20, P6.

1. Add a session note with tags. Edit it. Add three more, then try the filters.
2. On your phone, record a two-minute "session": you talking as clinician and parent. Lock the
   phone once in the middle.
3. Wait for the draft note. Does it match what was said? Rename a speaker. Approve it.
4. Chat: send the parent a message. As the parent, reply.

## Journey 6 — Wrapping up (10 min)
Checks: section 6, P7, 21.

1. Close treatment for the family. As the parent, reload: "All done for now"?
2. Reopen it. Does the parent's app come back?
3. Education: do one module and its quiz.
